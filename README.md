# QuantLab landing
Next.js (App Router) + React + Tailwind v4. Tokens: `DESIGN.md` → `app/globals.css`.

    npm install
    npm run dev      # http://localhost:3000

Deploy: push to GitHub and import in Vercel (framework preset: Next.js), or run `npx vercel`.
Replace the `#` hrefs (plans, login, download) with your real URLs.
